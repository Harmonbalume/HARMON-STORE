HARMON STORE — boutique en ligne
1. Ouvre index.html dans un navigateur pour voir la boutique.
2. Dans index.html, cherche WHATSAPP="243XXXXXXXXX" et remplace par ton numéro WhatsApp au format international, sans + ni espaces.
3. Modifie les prix/produits dans le tableau JavaScript `products` si nécessaire.
4. Pour publier le site, dépose index.html sur un hébergeur statique.
